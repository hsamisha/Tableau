Google Play Store Analytics — Tableau


This project focuses on analyzing Google Play Store app data using Tableau to understand app performance, user engagement, ratings, installations, pricing, app size, content ratings, and Android version compatibility.

An interactive Tableau dashboard was developed to transform raw app data into meaningful KPIs, charts, and visual insights that make it easier to explore and understand app trends.

🎯 Objectives
Analyze the distribution of apps across different categories.
Identify apps with high installation counts.
Compare Free vs Paid applications.
Analyze average app ratings.
Study the relationship between reviews and installs.
Analyze app size and its relationship with ratings.
Understand content-rating distribution.
Analyze Android version compatibility.
Compare app performance based on type and category.
Build interactive dashboards for easy data exploration.
